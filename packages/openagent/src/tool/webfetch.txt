- 从指定 URL 获取内容
- 接收 URL 和可选 format 作为输入
- 获取 URL 内容，并转换为请求的格式（默认 markdown）
- 以指定格式返回内容
- 当需要获取并分析 web 内容时使用此工具

用法说明：
  - 重要：如果存在另一个工具，其 web fetching 能力更强、更适合当前任务，或限制更少，优先使用那个工具而不是此工具。
  - URL 必须是完整有效的 URL
  - HTTP URLs 会自动升级为 HTTPS
  - Format 选项："markdown"（默认）、"text" 或 "html"
  - 此工具为只读，不会修改任何文件
  - 如果内容很大，结果可能会被总结
