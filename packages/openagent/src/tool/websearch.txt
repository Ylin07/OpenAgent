- 使用会话的 web search provider 搜索网络；执行实时 web 搜索，并可抓取特定 URLs 的内容
- 为当前事件和近期数据提供最新信息
- 支持可配置结果数量，并返回最相关网站的内容
- 当需要访问超出知识截止时间的信息时，使用此工具
- 搜索会在单次 API 调用中自动执行

用法说明：
  - 可用时支持 live crawling modes：'fallback'（缓存不可用时作为备选）或 'preferred'（优先 live crawling）
  - 可用时支持 search types：'auto'（均衡）、'fast'（快速结果）、'deep'（全面搜索）
  - 可配置 context length，以获得最佳 LLM 集成效果
  - 可用 domain filtering 和高级搜索选项

当前年份是 {{year}}。搜索近期信息或当前事件时，必须使用这一年份。
- 示例：如果当前年份是 2026，用户询问 "latest AI news"，搜索 "AI news 2026"，不要搜索 "AI news 2025"
