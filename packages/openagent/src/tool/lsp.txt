与 Language Server Protocol (LSP) servers 交互以获取代码智能功能。

支持的操作：
- goToDefinition：查找 symbol 定义位置
- findReferences：查找 symbol 的所有引用
- hover：获取 symbol 的 hover 信息（文档、类型信息）
- documentSymbol：获取文档中的所有 symbols（functions、classes、variables）
- workspaceSymbol：列出项目范围内匹配 query string 的 symbols
- goToImplementation：查找 interface 或 abstract method 的实现
- prepareCallHierarchy：获取某个位置的 call hierarchy item（functions/methods）
- incomingCalls：查找调用该位置 function 的所有 functions/methods
- outgoingCalls：查找该位置 function 调用的所有 functions/methods

所有操作都需要：
- filePath：要操作的文件
- line：行号（从 1 开始，与编辑器显示一致）
- character：字符偏移（从 1 开始，与编辑器显示一致）

workspaceSymbol 还接受：
- query：用于过滤 symbols 的 query string。空字符串表示请求所有 symbols。

对于 workspaceSymbol，filePath 不会发送到 LSP workspace/symbol 请求中。openagent 使用它来选择并启动匹配的 LSP server。

注意：必须为对应文件类型配置 LSP servers。如果没有可用 server，将返回错误。
